# Markdown nas anotações prévias

**Status:** aceito

As **Anotações prévias da reunião** e as **Anotações prévias do item** serão armazenadas e interpretadas como Markdown, pois representam o mesmo tipo de conteúdo preparatório e devem oferecer uma experiência de edição coerente. Esta decisão altera pontualmente o ADR 0001, que determinava texto simples para as Anotações prévias da reunião; **Ata** e **Transcrição** permanecem textos simples, sem interpretação de Markdown ou HTML.
