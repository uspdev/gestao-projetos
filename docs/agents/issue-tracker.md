# Rastreador de trabalho: Markdown local

Os tickets e as especificações deste repositório são arquivos Markdown em `.scratch/`.

## Convenções

- Uma funcionalidade por diretório: `.scratch/<feature-slug>/`.
- A especificação fica em `.scratch/<feature-slug>/spec.md`.
- Cada ticket fica em um arquivo próprio em `.scratch/<feature-slug>/issues/<NN>-<slug>.md`.
- A numeração começa em `01` e segue a ordem das dependências.
- O estado de triagem é registrado em uma linha `Status:` próxima do início de cada ticket.
- Tickets prontos usam `Status: ready-for-agent`.
