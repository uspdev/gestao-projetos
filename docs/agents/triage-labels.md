# Rótulos de triagem

| Papel canônico | Rótulo do repositório | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | A manutenção precisa avaliar o trabalho |
| `needs-info` | `needs-info` | Aguardando mais informações |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificado e pronto para um agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será realizado |
